## How to Connect Tools

### Option 1: Use Predefined Connectors

<Steps>
  <Step title="Go to Integrations">
    From dashboard, click **Integrations** → **Connectors**
  </Step>
  <Step title="Deploy Connector">
    Choose a connector (Gmail, Calendar, HubSpot, etc.) and deploy it as an MCP server
  </Step>
  <Step title="Add to Agent">
    Go to your agent's **Tools** tab → **Add Tool** → Select your deployed connector
  </Step>
</Steps>

### Option 2: Build a connector from an API specification

<Steps>
  <Step title="Go to Connectors">
    From dashboard, click **Integrations** → **Connectors** → **Custom**
  </Step>
  <Step title="Upload your specification">
    Provide an OpenAPI or Postman file. BoostGPT turns each operation into a tool and hosts the connector for you.
  </Step>
  <Step title="Add your credentials">
    Enter the key or token your API expects. It is encrypted and never shown again.
  </Step>
  <Step title="Add to Agent">
    Go to your agent's **Tools** tab → **Add Tool** → Select the connector
  </Step>
</Steps>

<Note>
  Your API must be reachable over **https** from the public internet. Addresses on a private network — `localhost`,
  `127.0.0.1`, `10.x`, `192.168.x` and similar — are refused, because BoostGPT would be making the request from
  inside its own network rather than from yours.
</Note>
