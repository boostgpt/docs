Spaces, lists and tasks. Another place work is tracked.

## Connecting

In the dashboard, open **Connectors**, find ClickUp and press **Connect**. The key you enter is checked against ClickUp before anything is saved, so a key that is refused never becomes a connection that fails later.

### What you will need

| Field | What it is |
|---|---|
| API Token | Your ClickUp API token |

### Getting the credential

1. Log in to [ClickUp](https://app.clickup.com)
2. Go to **Settings** → **Apps** → **API Token**
3. Click **"+ Generate"** and copy the token
4. Add token to connector

## Notes

- Uses API token authentication in Authorization header
- Rate limited to 100 requests per minute
- Supports custom task IDs and team-specific operations
- Structure: Workspace → Space → Folder → List → Task

See [ClickUp API docs](https://clickup.com/api) for complete reference.

## What an agent can do with it

| Tool | What it does |
|---|---|
| `get_authorized_user` | Get current authorized user information |
| `get_workspaces` | Get all workspaces for the authenticated user |
| `get_spaces` | Get spaces in a workspace |
| `create_space` | Create a new space |
| `get_folders` | Get folders in a space |
| `create_folder` | Create a folder in a space |
| `get_lists` | Get lists in a folder or space |
| `get_folderless_lists` | Get lists directly in a space (no folder) |
| `create_list` | Create a list in a folder |
| `create_folderless_list` | Create a list directly in a space |
| `get_tasks` | Get tasks in a list |
| `get_task` | Get a specific task by ID |
| `create_task` | Create a new task |
| `update_task` | Update an existing task |
| `delete_task` | Delete a task |
| `add_task_to_list` | Add an existing task to additional list |
| `get_task_comments` | Get comments for a task |
| `create_task_comment` | Create a comment on a task |
| `get_task_time_entries` | Get time tracking entries for a task |
| `track_time` | Track time on a task |
| `get_checklists` | Get checklists for a task |
| `create_checklist` | Create a checklist for a task |
| `create_checklist_item` | Create a checklist item |
| `get_team_members` | Get members of a workspace/team |
| `search_tasks` | Search for tasks across workspace |
| `get_task_templates` | Get task templates for a workspace |
| `create_task_from_template` | Create a task from a template |
| `get_custom_fields` | Get custom fields for a list |
| `set_custom_field_value` | Set custom field value for a task |
| `get_webhooks` | Get webhooks for a workspace |
| `create_webhook` | Create a webhook |
