Metrics, events, monitors and logs. Infrastructure health — nothing a marketing page claims.

## Connecting

In the dashboard, open **Connectors**, find DataDog and press **Connect**. The key you enter is checked against DataDog before anything is saved, so a key that is refused never becomes a connection that fails later.

### What you will need

| Field | What it is |
|---|---|
| API Key | Your DataDog API Key |
| Application Key | Your DataDog Application Key |

### Getting the credential

1. Log in to [DataDog](https://app.datadoghq.com)
2. Go to **Organization Settings** → **API Keys**
3. Create or copy an existing **API Key**
4. Go to **Organization Settings** → **Application Keys**
5. Create a new **Application Key**
6. Use both keys for authentication

## What an agent can do with it

| Tool | What it does |
|---|---|
| `submit_metrics` | Submit custom metrics to DataDog |
| `query_metrics` | Query metric data from DataDog |
| `get_events` | Get events from DataDog event stream |
| `create_event` | Create a new event in DataDog |
| `get_hosts` | Get list of hosts reporting to DataDog |
| `get_host_details` | Get detailed information about a specific host |
| `mute_host` | Mute alerts for a host |
| `get_dashboards` | List all dashboards |
| `create_dashboard` | Create a new dashboard |
| `get_monitors` | Get all monitors |
| `create_monitor` | Create a new monitor |
| `get_monitor` | Get details of a specific monitor |
| `update_monitor` | Update an existing monitor |
| `delete_monitor` | Delete a monitor |
| `get_downtimes` | Get all downtimes |
| `create_downtime` | Schedule a downtime |
| `get_logs` | Search logs |
| `get_service_map` | Get service map data |
