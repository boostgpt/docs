Repositories, issues, pull requests and releases. What actually shipped, so the homepage can stop describing the old version.

## Connecting

In the dashboard, open **Connectors**, find GitHub and press **Connect**. The key you enter is checked against GitHub before anything is saved, so a key that is refused never becomes a connection that fails later.

### What you will need

| Field | What it is |
|---|---|
| Personal Access Token | Your GitHub Personal Access Token with appropriate scopes |

### Getting the credential

1. Go to [GitHub Settings](https://github.com/settings/tokens)
2. Click **Developer settings** → **Personal access tokens** → **Tokens (classic)**
3. Click **Generate new token** → **Generate new token (classic)**
4. Select required scopes:
   - `repo` - Full repository access
   - `user` - User profile access
   - `admin:org` - Organization access (if needed)
   - `workflow` - GitHub Actions (if needed)
5. Copy the generated token

## What an agent can do with it

| Tool | What it does |
|---|---|
| `get_user` | Get user information |
| `get_user_repos` | List repositories for the authenticated user |
| `get_repo` | Get repository information |
| `create_repo` | Create a new repository |
| `get_issues` | List issues for a repository |
| `create_issue` | Create a new issue |
| `update_issue` | Update an existing issue |
| `get_pull_requests` | List pull requests for a repository |
| `create_pull_request` | Create a new pull request |
| `get_commits` | List commits for a repository |
| `get_branches` | List branches for a repository |
| `create_release` | Create a new release |
| `get_releases` | List releases for a repository |
| `search_repositories` | Search for repositories |
| `search_issues` | Search for issues and pull requests |
| `search_code` | Search for code |
| `search_users` | Search for users |
