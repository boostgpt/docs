Calendars and events. Meetings booked, for teams whose scheduling lives in Google.

## Connecting

In the dashboard, open **Connectors**, find Google Calendar and press **Connect**. You will be sent to sign in; the connection is saved once that succeeds.

### What you will need

| Field | What it is |
|---|---|
| Client ID | Your Google OAuth 2.0 Client ID |
| Client Secret | Your Google OAuth 2.0 Client Secret |

### Getting the credential

1. Go to [Google Cloud Console](https://console.cloud.google.com)
2. Create project → Enable **Calendar API**
3. Create **OAuth 2.0 credentials**
4. Add authorized redirect URIs
5. Add Client ID and Secret to connector

## Notes

- Access is per calendar: the OAuth account has to have been granted the calendar you name, and the
  primary calendar id is literally `primary`.
- Requires OAuth 2.0 with appropriate scopes
- Rate limited (varies by quota tier)
- Supports recurring events with RRULE
- Conference data requires additional permissions
- Proper time zone handling with RFC3339 format

See [Google Calendar API docs](https://developers.google.com/calendar/api) for complete reference.

## What an agent can do with it

| Tool | What it does |
|---|---|
| `get_calendar_list` | Get list of calendars for the authenticated user |
| `get_calendar` | Get metadata for a specific calendar |
| `create_calendar` | Create a new secondary calendar |
| `update_calendar` | Update calendar metadata |
| `delete_calendar` | Delete a secondary calendar |
| `get_events` | Get events from a calendar |
| `get_event` | Get a specific event |
| `create_event` | Create a new event |
| `update_event` | Update an existing event |
| `delete_event` | Delete an event |
| `move_event` | Move an event to another calendar |
| `get_freebusy` | Get free/busy information |
| `quick_add_event` | Create event using natural language |
| `get_colors` | Get available colors for calendars and events |
