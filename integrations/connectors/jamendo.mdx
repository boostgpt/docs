Creative-commons music tracks, searchable. Licensed background audio for a video.

## Connecting

In the dashboard, open **Connectors**, find Jamendo and press **Connect**. The key you enter is checked against Jamendo before anything is saved, so a key that is refused never becomes a connection that fails later.

### What you will need

| Field | What it is |
|---|---|
| Client ID | Your Jamendo application Client ID from developer.jamendo.com |

### Getting the credential

Register an application at https://developer.jamendo.com to get your Client ID. In the bot tool configuration, add a Custom Header — key: x-client-id, value: your Client ID.

## Notes

- All music is Creative Commons licensed — check `license_ccurl` for the specific terms
- The `audio` URL provides a 30-second preview; `audiodownload` provides the full track
- See the [Jamendo API docs](https://developer.jamendo.com/v3.0) for full parameter reference

## What an agent can do with it

| Tool | What it does |
|---|---|
| `search_tracks` | Search music tracks by name, artist, tags (genres, moods, instruments), or browse by popularity. Returns track metadata including streaming URL, download URL, album art, artist, duration, and license. |
| `get_track` | Get detailed metadata for a specific track by its Jamendo ID. Returns the same fields as search_tracks for a single track. |
| `search_albums` | Search music albums by name or artist. Returns album metadata including cover image, release date, and track count. |
| `get_album_tracks` | Get all tracks in a specific album by its Jamendo album ID. Returns full track metadata including streaming URLs. |
| `search_artists` | Search for artists on Jamendo by name. Returns artist metadata including website, image, and location. |
| `get_artist_tracks` | Get tracks by a specific artist using their Jamendo artist ID. Returns full track metadata including streaming URLs. |
