Lists, members, campaigns and reports. The audience that already said yes — and what they opened.

## Connecting

In the dashboard, open **Connectors**, find Mailchimp and press **Connect**. The key you enter is checked against Mailchimp before anything is saved, so a key that is refused never becomes a connection that fails later.

### What you will need

| Field | What it is |
|---|---|
| API Key | Your Mailchimp API key (includes data center suffix) |
| Data Center | The data centre in your account URL, e.g. us21 |

### Getting the credential

1. Log in to [Mailchimp](https://mailchimp.com)
2. Go to **Account** → **Extras** → **API keys**
3. Click **Create A Key**
4. Copy the generated API key (includes data center suffix like -us1)
5. Use the full API key to configure this connector

## What an agent can do with it

| Tool | What it does |
|---|---|
| `get_lists` | Get all audience lists |
| `get_list` | Get information about a specific list |
| `create_list` | Create a new audience list |
| `get_list_members` | Get members from a list |
| `add_list_member` | Add a new member to a list |
| `update_list_member` | Update a list member |
| `delete_list_member` | Remove a member from a list |
| `get_campaigns` | Get all campaigns |
| `create_campaign` | Create a new campaign |
| `get_campaign_content` | Get campaign content |
| `set_campaign_content` | Set campaign content |
