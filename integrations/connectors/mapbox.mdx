Geocoding, directions and static maps. For a product that needs maps; a page rarely does.

## Connecting

In the dashboard, open **Connectors**, find Mapbox and press **Connect**. The key you enter is checked against Mapbox before anything is saved, so a key that is refused never becomes a connection that fails later.

### What you will need

| Field | What it is |
|---|---|
| Access Token | Your Mapbox access token with appropriate scopes |

### Getting the credential

1. Sign up at [Mapbox](https://www.mapbox.com)
2. Go to **Account** → **Access Tokens**
3. Create a new token or use your default public token
4. For advanced features, configure token scopes:
   - Public scopes: No restrictions needed
   - Secret scopes: Add specific API permissions

## Notes

- Free tier: 50,000 requests/month for most APIs
- Static Images API: 50,000 requests/month
- Paid plans: Higher limits available

## What an agent can do with it

| Tool | What it does |
|---|---|
| `geocode_forward` | Convert addresses or place names to coordinates |
| `geocode_reverse` | Convert coordinates to addresses or place names |
| `get_directions` | Get directions between coordinates |
| `get_matrix` | Get travel times and distances between multiple points |
| `get_optimization` | Solve traveling salesman problem for route optimization |
| `get_isochrone` | Get isochrone (areas reachable within time/distance) |
| `get_map_matching` | Snap GPS traces to road network |
| `get_static_map` | Generate static map images |
| `search_places` | Search for points of interest and places |
| `get_place_details` | Get detailed information about a specific place |
| `get_tilesets` | List available tilesets |
| `get_tileset_metadata` | Get metadata for a specific tileset |
