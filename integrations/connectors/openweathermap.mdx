Current weather, forecasts and air quality. Here because an agent may need it, not because a page does.

## Connecting

In the dashboard, open **Connectors**, find OpenWeatherMap and press **Connect**. The key you enter is checked against OpenWeatherMap before anything is saved, so a key that is refused never becomes a connection that fails later.

### What you will need

| Field | What it is |
|---|---|
| API Key | Your OpenWeatherMap API key |

### Getting the credential

1. Sign up at [OpenWeatherMap](https://openweathermap.org/api)
2. Go to **API Keys** section in your account
3. Copy your default API key or create a new one
4. For advanced features, consider upgrading to a paid plan

## Notes

- Free tier: 1,000 calls/day, 60 calls/minute
- Paid plans: Higher limits available

See [OpenWeatherMap API docs](https://openweathermap.org/api) for full details.

## What an agent can do with it

| Tool | What it does |
|---|---|
| `get_current_weather` | Get current weather data for a location |
| `get_5day_forecast` | Get 5 day weather forecast with 3 hour step |
| `get_hourly_forecast` | Get hourly forecast for 48 hours |
| `get_onecall_weather` | Get current and forecast weather data including minute forecast for 1 hour, hourly forecast for 48 hours, daily forecast for 8 days |
| `get_historical_weather` | Get historical weather data for a specific date |
| `get_air_pollution` | Get current air pollution data |
| `get_air_pollution_forecast` | Get air pollution forecast for 5 days |
| `get_air_pollution_history` | Get historical air pollution data |
| `get_geocoding` | Get geographical coordinates by location name |
| `get_reverse_geocoding` | Get location names by geographical coordinates |
| `get_weather_maps` | Get weather map tiles |
