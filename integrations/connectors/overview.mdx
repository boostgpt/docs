---
title: "Connectors"
description: "Every service BoostGPT connects to, and what each one is for"
---

BoostGPT builds and maintains these. You enter one credential and the tools stay working — when a vendor
changes an endpoint, that is ours to fix, not yours.

They are grouped by the part of the loop they serve, and the featured ones in each group are the ones that
change what the Site says or what the Widget answers.

<Note>
  A key is checked against the vendor before a connection is saved. A key the vendor refuses never becomes a
  connection that looks fine and fails on its first real call.
</Note>

## Make images, video and voice for the site

<CardGroup cols={2}>
  <Card title="ElevenLabs" href="/integrations/connectors/elevenlabs">
    Speech, transcription, sound effects and music. Voice-over for a demo, and transcripts of calls the site should answer.
  </Card>
  <Card title="fal.ai" href="/integrations/connectors/fal-ai">
    Any model hosted on fal.ai, called by id. Use it when a page needs a model the other connectors do not carry.
  </Card>
  <Card title="Google Gemini" href="/integrations/connectors/google-gemini">
    Text, images, speech and video from Gemini. A second opinion on any of them, and the cheapest route to long video.
  </Card>
  <Card title="Higgsfield" href="/integrations/connectors/higgsfield">
    Image and video generation, including camera-motion animation. For a hero video that would otherwise need a shoot.
  </Card>
  <Card title="OpenAI" href="/integrations/connectors/openai">
    Images, image edits and speech from OpenAI. The default way Boost makes a picture or a voice-over for a page.
  </Card>
  <Card title="Replicate" href="/integrations/connectors/replicate">
    Any model hosted on Replicate, called by id. The same escape hatch as fal.ai, over a different catalogue.
  </Card>
  <Card title="FLUX (Black Forest Labs)" href="/integrations/connectors/flux">
    Image generation and editing from Black Forest Labs. Another look, when OpenAI's house style is not the one you want.
  </Card>
  <Card title="GitHub" href="/integrations/connectors/github">
    Repositories, issues, pull requests and releases. What actually shipped, so the homepage can stop describing the old version.
  </Card>
  <Card title="HeyGen" href="/integrations/connectors/heygen">
    Avatar videos from a script, with stock voices. A talking-head explainer without filming one.
  </Card>
  <Card title="Ideogram" href="/integrations/connectors/ideogram">
    Image generation, including transparent output. The one that renders legible text inside an image.
  </Card>
  <Card title="Luma Labs" href="/integrations/connectors/luma-labs">
    Video and image generation, including image-to-video. An alternative to Higgsfield for a moving hero.
  </Card>
  <Card title="Mureka" href="/integrations/connectors/mureka-ai">
    Songs, instrumentals and lyrics. Background music for a demo video — rarely something a page itself needs.
  </Card>
  <Card title="Pexels" href="/integrations/connectors/pexels">
    Free stock photos and video. The quickest way to fill a page before there is art direction. BoostGPT funds the key.
  </Card>
  <Card title="Recraft" href="/integrations/connectors/recraft">
    Raster and vector image generation. It produces real SVG, which is what a logo or an icon on a page should be.
  </Card>
  <Card title="Runway" href="/integrations/connectors/runway-ai">
    Video generation, image-to-video and upscaling. A second video model, with a different house look.
  </Card>
  <Card title="Stability AI" href="/integrations/connectors/stability-ai">
    Image generation, upscaling, background removal and search-and-replace. More post-production than the others.
  </Card>
  <Card title="Unsplash" href="/integrations/connectors/unsplash">
    Stock photography, searchable. Real photographs, for the places where a generated image looks generated.
  </Card>
  <Card title="xAI" href="/integrations/connectors/xai">
    Image and video generation from xAI. Another model to reach for when a page needs a different look.
  </Card>
  <Card title="Linear" href="/integrations/connectors/linear">
    Issues, teams and cycles, with an API key. The Linear server above signs in instead — use this to hold a key rather than a session.
  </Card>
  <Card title="Notion" href="/integrations/connectors/notion">
    Pages, databases and search, with an integration token. The Notion server above signs in instead.
  </Card>
  <Card title="Sentry" href="/integrations/connectors/sentry">
    Issues, events and releases, with a token. The Sentry server above signs in instead. Product health, not what a page should say.
  </Card>
</CardGroup>

## Research what people search for and ask

<CardGroup cols={2}>
  <Card title="Firecrawl" href="/integrations/connectors/firecrawl">
    Scrape, crawl and map a site into clean text. Point it at a competitor to see how they explain what you also do.
  </Card>
  <Card title="Intercom" href="/integrations/connectors/intercom">
    Support conversations, contacts and help articles. A question asked five times is a page the site has not written yet.
  </Card>
  <Card title="Serper (Google Search)" href="/integrations/connectors/serper">
    Google results, People Also Ask, news and shopping. Use it to find the words customers use before they know your product exists.
  </Card>
  <Card title="Apify" href="/integrations/connectors/apify">
    Thousands of ready-made scrapers, run by id. For the source with no API — a directory, a review site.
  </Card>
  <Card title="BrowseAgent" href="/integrations/connectors/browseagent">
    Drives a real browser: navigate, click, screenshot. For what only appears after JavaScript, or behind a login.
  </Card>
  <Card title="Cal.com" href="/integrations/connectors/calcom">
    Event types and bookings. Did the call to action work — is anybody actually booking the call?
  </Card>
  <Card title="Exa" href="/integrations/connectors/exa">
    Search by meaning rather than keyword, with page contents. Finds pages that discuss a problem, not ones that match a phrase.
  </Card>
  <Card title="HubSpot" href="/integrations/connectors/hubspot">
    Contacts, companies and deals. Who asked, what they asked about, and whether it ever closed.
  </Card>
  <Card title="ScreenshotOne" href="/integrations/connectors/screenshotone">
    Screenshots of any URL, still or animated. See a page the way a visitor does — yours or a competitor's.
  </Card>
  <Card title="Shopify" href="/integrations/connectors/shopify">
    Products, orders and customers. What a store actually sells, which is what its pages should lead with.
  </Card>
  <Card title="Tavily" href="/integrations/connectors/tavily">
    Search, extract and crawl, built for agents. A second reader for when Firecrawl is blocked.
  </Card>
  <Card title="URLBox" href="/integrations/connectors/urlbox">
    Rendered screenshots and PDFs of a URL. The same job as ScreenshotOne, a different renderer.
  </Card>
  <Card title="Bing Search" href="/integrations/connectors/bing-search">
    Web, news, image and video search. Another index, useful mainly for comparing what different engines surface.
  </Card>
  <Card title="Brave Search" href="/integrations/connectors/brave-search">
    Web, news and image search on its own index. A fallback when Google's results are not available.
  </Card>
  <Card title="Calendly" href="/integrations/connectors/calendly">
    Scheduled events, invitees and event types. The same question as Cal.com, for teams on Calendly.
  </Card>
  <Card title="Google Calendar" href="/integrations/connectors/google-calendar">
    Calendars and events. Meetings booked, for teams whose scheduling lives in Google.
  </Card>
  <Card title="Mixpanel" href="/integrations/connectors/mixpanel">
    Events, funnels and insights, with an API key. The Mixpanel server above signs in instead.
  </Card>
  <Card title="Paddle Billing" href="/integrations/connectors/paddle-billing">
    Transactions, subscriptions and invoices. The end of the funnel, for teams billing through Paddle.
  </Card>
  <Card title="PayPal" href="/integrations/connectors/paypal">
    Orders, captures and refunds. Revenue, for teams taking PayPal.
  </Card>
  <Card title="Square" href="/integrations/connectors/square">
    Payments, refunds and catalogue. Revenue, for teams selling through Square.
  </Card>
  <Card title="Stripe Payments" href="/integrations/connectors/stripe">
    Payments, customers, subscriptions and refunds, with an API key. The Stripe server above signs in instead.
  </Card>
  <Card title="Zendesk" href="/integrations/connectors/zendesk">
    Tickets, users and help-centre articles, with an API token. The Zendesk server above signs in instead.
  </Card>
</CardGroup>

  </Card>

## Bringing your own

**Add your own** on the Connectors screen takes either an OpenAPI specification or a Postman
collection and turns it into a connector, or the address of an MCP server somebody else runs —
see [remote MCP servers](/integrations/remote-mcp).
