Transactional email, bounces and templates. The mail a signup triggers, and whether it arrived.

## Connecting

In the dashboard, open **Connectors**, find SendGrid and press **Connect**. The key you enter is checked against SendGrid before anything is saved, so a key that is refused never becomes a connection that fails later.

### What you will need

| Field | What it is |
|---|---|
| API Key | Your SendGrid API key |

### Getting the credential

1. Log in to [SendGrid Console](https://app.sendgrid.com)
2. Go to **Settings** → **API Keys**
3. Click **Create API Key**
4. Choose **Restricted Access** and select required permissions:
   - Mail Send (for sending emails)
   - Stats (for analytics)
   - Suppressions (for bounce/block management)
   - Template Engine (for templates)
   - Marketing Campaigns (for contacts)
5. Copy the generated API key

## What an agent can do with it

| Tool | What it does |
|---|---|
| `send_email` | Send an email message |
| `get_email_stats` | Get email delivery statistics |
| `get_bounces` | Get bounced email addresses |
| `delete_bounce` | Remove an email from bounce list |
| `get_blocks` | Get blocked email addresses |
| `delete_block` | Remove an email from block list |
| `get_templates` | Get email templates |
| `get_template` | Get a specific email template |
| `create_template` | Create a new email template |
| `get_contacts` | Get marketing contacts |
| `add_contacts` | Add or update marketing contacts |
