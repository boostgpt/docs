Issues, events and releases, with a token. The Sentry server above signs in instead. Product health, not what a page should say.

## Connecting

In the dashboard, open **Connectors**, find Sentry and press **Connect**. The key you enter is checked against Sentry before anything is saved, so a key that is refused never becomes a connection that fails later.

### What you will need

| Field | What it is |
|---|---|
| Auth Token | Your Sentry Auth Token with appropriate scopes |
| Organization Slug | Your Sentry organization slug, from the URL |
| Project Slug | Your Sentry project slug, from the URL |

### Getting the credential

1. Log in to [Sentry](https://sentry.io)
2. Go to **Settings** → **Account** → **API** → **Auth Tokens**
3. Click **Create New Token**
4. Select required scopes:
   - `org:read` - Read organization data
   - `project:read` - Read project data
   - `event:read` - Read error events
   - `issue:write` - Update issues
   - `project:releases` - Manage releases
5. Copy the generated token

## What an agent can do with it

| Tool | What it does |
|---|---|
| `get_organizations` | List organizations you belong to |
| `get_projects` | List projects in an organization |
| `get_issues` | List issues for a project |
| `get_issue` | Get details of a specific issue |
| `update_issue` | Update an issue (resolve, assign, etc.) |
| `get_events` | List events for an issue |
| `get_event` | Get details of a specific event |
| `get_project_stats` | Get project statistics |
| `get_releases` | List releases for a project |
| `create_release` | Create a new release |
| `get_teams` | List teams in an organization |
| `get_members` | List organization members |
| `search_events` | Search for events across projects |
| `get_user_feedback` | Get user feedback for a project |
