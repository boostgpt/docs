Google results, People Also Ask, news and shopping. Use it to find the words customers use before they know your product exists.

## Connecting

In the dashboard, open **Connectors**, find Serper (Google Search) and press **Connect**. The key you enter is checked against Serper (Google Search) before anything is saved, so a key that is refused never becomes a connection that fails later.

### What you will need

| Field | What it is |
|---|---|
| API Key | Your Serper.dev API key |

### Getting the credential

1. Sign up at [Serper.dev](https://serper.dev)
2. Go to **Dashboard** → **API Keys**
3. Copy your API key
4. Add API key to connector

## What an agent can do with it

| Tool | What it does |
|---|---|
| `web_search` | Search the web using Google search. Returns organic results, snippets, and links. |
| `news_search` | Search for news articles using Google News |
| `image_search` | Search for images using Google Images |
| `video_search` | Search for videos using Google Videos |
| `places_search` | Search for local places and businesses using Google Maps |
| `shopping_search` | Search for products using Google Shopping |
| `scholar_search` | Search for academic papers and citations using Google Scholar |
| `patents_search` | Search for patents using Google Patents |
