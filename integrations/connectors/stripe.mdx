Read-only: customers, subscriptions, products, prices, invoices and balance, with an API key. The Stripe server above signs in instead.

## Connecting

In the dashboard, open **Connectors**, find Stripe Payments and press **Connect**. The key you enter is checked against Stripe Payments before anything is saved, so a key that is refused never becomes a connection that fails later.

### What you will need

| Field | What it is |
|---|---|
| Restricted key (read-only) | A Stripe restricted key with read access (rk_…). A secret key (sk_…) also works, but this connector only reads, so it needs no more than that. |

### Getting the credential

1. Create a [Stripe account](https://dashboard.stripe.com/register)
2. Go to **Developers** → **API keys** → **Create restricted key**
3. Give it **Read** access to Customers, Subscriptions, Products, Prices, Invoices, Payment Intents and Balance, and nothing else
4. Copy the key (starts with `rk_test_` or `rk_live_`) and paste it here

## What an agent can do with it

| Tool | What it does |
|---|---|
| `get_payment_intent` | Retrieve a payment intent |
| `get_customer` | Retrieve a customer |
| `list_customers` | List all customers |
| `get_subscription` | Retrieve a subscription |
| `list_subscriptions` | List subscriptions |
| `list_products` | List products |
| `list_prices` | List prices |
| `list_invoices` | List invoices |
| `get_balance` | Get account balance |
