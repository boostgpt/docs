Boards, lists and cards. Another place work is tracked.

## Connecting

In the dashboard, open **Connectors**, find Trello and press **Connect**. The key you enter is checked against Trello before anything is saved, so a key that is refused never becomes a connection that fails later.

### What you will need

| Field | What it is |
|---|---|
| API Key | Your Trello API Key |
| API Token | Your Trello API Token |

### Getting the credential

1. Get **API Key**: Visit [https://trello.com/app-key](https://trello.com/app-key)
2. Generate **Token**: Click token link on API key page
3. Choose permissions (read/write) and expiration
4. Add both API Key and Token to connector

## Notes

- Uses API Key + Token authentication via query parameters
- Rate limited to 300 requests per 10 seconds
- Structure: Boards → Lists → Cards
- Supports webhooks for real-time updates

See [Trello API docs](https://developer.atlassian.com/cloud/trello/rest/api-group-actions/) for complete reference.

## What an agent can do with it

| Tool | What it does |
|---|---|
| `get_member_boards` | Get boards for the authenticated member |
| `get_board` | Get a specific board by ID |
| `create_board` | Create a new board |
| `get_board_lists` | Get lists on a board |
| `create_list` | Create a new list on a board |
| `get_list_cards` | Get cards in a list |
| `create_card` | Create a new card |
| `get_card` | Get a specific card by ID |
| `update_card` | Update an existing card |
| `delete_card` | Delete a card |
| `add_comment_to_card` | Add a comment to a card |
| `get_card_actions` | Get actions (activity) for a card |
| `create_checklist` | Create a checklist on a card |
| `add_checklist_item` | Add an item to a checklist |
| `update_checklist_item` | Update a checklist item |
| `get_board_members` | Get members of a board |
| `add_member_to_board` | Add a member to a board |
| `search_trello` | Search across Trello boards, cards, and members |
| `get_board_labels` | Get labels on a board |
| `create_label` | Create a label on a board |
