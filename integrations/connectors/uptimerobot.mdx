Monitors, alert contacts and maintenance windows. Whether the site is up, which is not the same as whether it is right.

## Connecting

In the dashboard, open **Connectors**, find UptimeRobot and press **Connect**. The key you enter is checked against UptimeRobot before anything is saved, so a key that is refused never becomes a connection that fails later.

### What you will need

| Field | What it is |
|---|---|
| API Key | Your UptimeRobot API key |

### Getting the credential

1. Log in to [UptimeRobot Dashboard](https://dashboard.uptimerobot.com)
2. Go to **Integrations & API** → **API**
3. Generate **Main API Key** or create specific keys
4. Add API key to connector

## Notes

- The free plan checks every five minutes, so a short outage can pass unseen.
- Creating a monitor needs the account's main API key; a monitor-specific key can only read.

## What an agent can do with it

| Tool | What it does |
|---|---|
| `get_monitors` | Get list of monitors |
| `get_monitor` | Get a specific monitor by ID |
| `create_monitor` | Create a new monitor |
| `update_monitor` | Update an existing monitor |
| `delete_monitor` | Delete a monitor |
| `reset_monitor` | Reset monitor statistics |
| `get_alert_contacts` | Get list of alert contacts |
| `get_alert_contact` | Get a specific alert contact |
| `create_alert_contact` | Create a new alert contact |
| `update_alert_contact` | Update an alert contact |
| `delete_alert_contact` | Delete an alert contact |
| `get_maintenance_windows` | Get list of maintenance windows |
| `create_maintenance_window` | Create a new maintenance window |
| `update_maintenance_window` | Update a maintenance window |
| `delete_maintenance_window` | Delete a maintenance window |
| `get_status_pages` | Get list of public status pages |
| `create_status_page` | Create a new public status page |
| `update_status_page` | Update a public status page |
| `delete_status_page` | Delete a public status page |
| `get_account_details` | Get account information and limits |
