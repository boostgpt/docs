Projects, deployments and domains. Where a site built elsewhere is hosted and shipped.

## Connecting

In the dashboard, open **Connectors**, find Vercel and press **Connect**. The key you enter is checked against Vercel before anything is saved, so a key that is refused never becomes a connection that fails later.

### What you will need

| Field | What it is |
|---|---|
| API Token | Your Vercel API token |

### Getting the credential

1. Log in to [Vercel Dashboard](https://vercel.com/dashboard)
2. Go to **Settings** → **Tokens**
3. Click **Create Token**
4. Enter a token name and select scopes
5. Choose expiration period
6. Copy the generated token

## What an agent can do with it

| Tool | What it does |
|---|---|
| `get_user` | Get current user information |
| `get_teams` | List teams you belong to |
| `get_projects` | List projects |
| `get_project` | Get project details |
| `create_project` | Create a new project |
| `update_project` | Update project settings |
| `delete_project` | Delete a project |
| `get_deployments` | List deployments |
| `get_deployment` | Get deployment details |
| `create_deployment` | Create a new deployment |
| `cancel_deployment` | Cancel a deployment |
| `get_domains` | List domains |
| `get_domain` | Get domain details |
| `get_environment_variables` | List environment variables for a project |
| `create_environment_variable` | Create environment variable |
| `get_logs` | Get deployment logs |
